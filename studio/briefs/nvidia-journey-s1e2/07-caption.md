AI ⊃ machine learning ⊃ deep learning ⊃ generative AI. Related, but not the same thing:
• Rule-based clinical systems follow rules written by experts
• Machine learning learns patterns from patient history (like predicting hospitalisation risk)
• Deep learning recognises patterns in images, language and signals
• Generative AI creates new text, images and code

Next time someone says "we use AI", ask: "Show me what it does in my working day."
