# Daily run settings

Read by /reel-daily on every scheduled run. Change these lines to change the run.

- **Schedule:** Mon, Wed, Fri; run starts 08:29 IST, script delivered around 09:00 IST
- **Mode:** half-auto       (auto = the system voices it; half-auto = script first, you record, then video)
- **Language:** en
- **Length:** 30-45 s (about 80-110 spoken words)
- **Voice:** your recording (Voice Memos, Lossless), imported with `vo.py --audio`
- **Style:** animated explainer, brand kit
- **Topics:** AI in healthcare, doctor workflows, patient care between visits, DocX/Treint where relevant
- **Never:** individual medical advice, drug dosing, named patients, unverified claims, politics
