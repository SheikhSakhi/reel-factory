# reel-factory

A team of AI agents in **Claude Code** that runs a short-form content system: it finds ideas that work in your niche, writes them in proven formats, and turns each one into a finished, **on-brand** 9:16 reel with a voice-over, word-timed captions, a cover, and a ready-to-post caption with a keyword CTA. Every frame is animated in code with [Remotion](https://www.remotion.dev), not generated by a video model, so each reel is sharp, editable and reproducible.

https://github.com/SheikhSakhi/reel-factory/raw/main/docs/series-demo.mp4

*`series-demo`: the brand template in action. Fixed look, series chrome, voice-synced beats, a real proof shot and a keyword CTA, made by the pipeline below.*

## Why it works

Accounts grow from **consistency and trust**, not one good-looking video. So the factory is built around five things:

1. **One brand look.** Set it once with `/reel-brand`. Every reel uses the same palette, fonts, headline highlight, counter, chapter tabs and caption pill, so people recognise you before they read a word.
2. **A voice that drives everything.** Voice-over is on by default (free, no API key). Captions follow it word by word, and every animation lands on the word it illustrates.
3. **Proven formats with visible progress.** Numbered list, before/after, myth vs fact, tutorial, story, hot take ([formats.md](skills/reel-factory/formats.md)). The first 3 seconds must contain a promise and a proof, and QA fails the reel if they don't.
4. **Real proof.** Your screenshots, screen recordings and real comments go into proof scenes (phone or browser frames with highlight boxes). Nothing is invented.
5. **A CTA that captures leads.** "Comment GUIDE and I'll DM you…" with a pinned button-style end card, a caption that recaps the reel, the DM text, and reply drafts.

## The commands

| Command | What it does |
|---|---|
| `/reel-brand` | Sets your brand once: look, fonts (stored locally), voice, proof points, CTA keyword and lead magnets. Shows a preview to approve. |
| `/reel-edit <link or file>` | Edits your own recording from a Google Drive / Dropbox link or a file: cleans the audio, transcribes it locally, cuts retakes and dead air, reframes to 9:16 around your face, and adds creator-style captions, callouts, a name plate, counting stats, arrows, big-word slams, picture-in-picture, punch-in zooms, flashes, sound effects and the CTA. Revisions in plain words ("remove the box at 12 s"). |
| `/reel-insights` | The weekly loop: pulls your reels' insights and your watchlist's posts from Instagram, finds outliers, tags them, and reports what works for your audience and your niche. |
| `/reel-ideas` | Researches what's working in your niche now. Adds scored ideas (format, hook, proof, CTA, effort) to `ideas/backlog.md`. |
| `/reel-adapt <url or file>` | Breaks a viral reel down into a beat map and makes your version with the same structure, using your topic and brand. Never their words or visuals. |
| `/reel-factory <idea>` | Makes one reel end to end: MP4, cover and caption. |
| `/reel-plan` | Plans a Monday to Sunday week with a balanced mix of formats and CTAs, then batch-produces it. |
| `/reel-replies` | Drafts replies to comments and DMs: keyword DMs, answers, thanks, and what to ignore. You approve every send. |

## The team

`/reel-factory` runs this pipeline:

| Agent | Job |
|---|---|
| `reel-researcher` | angle, hooks (promise + proof), verified facts, proof material |
| `reel-scriptwriter` | format, scene-by-scene script, one-take voice-over |
| `reel-art-director` | per-scene compositions and proof visuals **inside** the brand kit |
| `reel-sound-director` | sound-effect cues synced to spoken words |
| `reel-caption-writer` | caption with recap, keyword CTA, hashtags, DM text, pinned comment |
| `reel-animator` | builds the reel in Remotion, typechecks, renders previews |
| `reel-qa` | checks the hook rule, format, brand, proof, layout and audio, then returns PASS or a list of fixes |
| `reel-trend-scout` | ideas for `/reel-ideas`, teardowns for `/reel-adapt` |

It never publishes or sends anything on its own. It always asks first. Publishing, comment replies and keyword DMs go through the official Instagram API (`scripts/ig.py`) once you connect it.

## How it learns

```
research (Instagram outliers, YouTube Shorts, web) → make (script or your recording) → publish → measure (insights) → research
```

Everything it learns goes into one local database (`data/factory.db`); the research and script agents read the summaries (`insights/report.md`, `insights/formats.md`, `ideas/outliers.md`) before writing. Details: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Connect Instagram and YouTube

Free, about an hour, once: [docs/SETUP.md](docs/SETUP.md). It unlocks publishing, insights, comment replies, keyword DMs and competitor research. Everything else works without it.

## Install

**Easiest:** paste this into Claude Code:

> Install this: https://github.com/SheikhSakhi/reel-factory — clone it and run install.sh

**Manual:**

```bash
git clone https://github.com/SheikhSakhi/reel-factory.git
cd reel-factory && sh install.sh
```

Requirements: Node.js 18+, python3, git. For editing your own recordings: ffmpeg (`brew install ffmpeg` / `apt install ffmpeg`); the installer adds OpenCV, and whisper.cpp builds itself on first use. The first render downloads Remotion's headless Chrome automatically. No paid API keys are needed.

**Upgrading:** `git pull && sh install.sh`. The installer refreshes the kit, scripts and examples. It keeps your brand, reels, briefs and registry, and backs up any kit file you changed to `.backup/<time>/`.

Restart Claude Code after installing.

## Use

```
/reel-brand
/reel-factory 5 ways doctors can use AI agents - 45s, CTA "comment AGENT"
```

You get `~/Projects/reel-studio/out/<slug>.mp4`, `out/<slug>-cover.jpg` and `briefs/<slug>/07-caption.md`. Run `npm run studio` inside `~/Projects/reel-studio` to tweak a reel by hand in the live editor.

## Voice-over (on by default, free, no API key)

1. The scriptwriter writes the voice-over as one conversational script, `briefs/<slug>/vo-take.txt`, with `[S1]`, `[S2]` … scene markers.
2. `npm run vo -- <slug>` synthesizes it in one take with Microsoft's neural voices through [edge-tts](https://github.com/rany2/edge-tts). One take sounds natural instead of choppy.
3. It writes `take.json`, which holds every scene's frame range and every word's timing.
4. The reel cuts scenes on those ranges, lands animations on spoken words, and shows word-by-word captions.
5. `npm run audio-check -- <slug>` confirms the mix doesn't clip.

To change the wording later, edit `vo-take.txt` and run `npm run vo -- <slug>` again; the reel retimes itself. Say "no voice" in your request for a text-only reel. If you get a 403 error, update the package with `pip3 install -U edge-tts`.

Note: the script text is sent to Microsoft's TTS service, and edge-tts is an unofficial client.

## The brand kit

- `brand/brand.md`: decisions every agent reads (niche, audience, proof points, voice, CTA keyword, lead magnets, hashtags, rules).
- `src/brand/brand.ts`: the code every reel imports (`BRAND`: theme, contrast theme, fonts, highlight style, chrome, captions, CTA).
- `public/fonts/`: the brand fonts, stored locally by `npm run fonts`, so renders work offline and never change.
- Kit components: `Headline` (one `*accented*` word), `SeriesChrome` (counter, chapter label, tabs, progress bar), `ProofShot`, `CommentCard`, `StatCard` (source required), `CtaCard`, `Captions` (pill or plain).

## What gets installed

- `~/.claude/skills/reel-*`: the 8 skills (`reel-factory` with `formats.md`, `reel-brand`, `reel-edit`, `reel-insights`, `reel-ideas`, `reel-adapt`, `reel-plan`, `reel-replies`)
- `~/.claude/agents/reel-*.md`: the 8 agents
- `~/Projects/reel-studio/`: the Remotion project (brand kit, animation kit, two example reels) and its scripts: `edit.py` + `align.py` + `transcribe.mjs` (own-footage editor), `ig.py` (Instagram), `trends.py` (research), `db.py` (memory), `vo.py`, `fonts.py`, `frames.sh`, render, QA and audio check, plus unit tests (`npm test`). Set `REEL_STUDIO_DIR` to put it somewhere else.
