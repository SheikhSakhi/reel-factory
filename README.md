# reel-factory

A team of AI agents in **Claude Code** that turns one idea into a finished 9:16 motion-graphics reel. Every frame is animated in code with [Remotion](https://www.remotion.dev), not generated by a video model, so each reel is sharp, editable and gets its own visual style.

https://github.com/SheikhSakhi/reel-factory/raw/main/docs/demo.mp4

## The team

`/reel-factory` runs this pipeline:

| Agent | Job |
|---|---|
| `reel-researcher` | angle, hooks, verified facts |
| `reel-scriptwriter` | scene-by-scene script with on-screen text |
| `reel-art-director` | a new palette, fonts and motion style for every reel |
| `reel-sound-director` | frame-accurate sound-effect cue sheet |
| `reel-animator` | builds the reel in Remotion, then typechecks and renders previews |
| `reel-qa` | checks every scene, then returns PASS or a list of fixes |

It never publishes on its own. It always asks first, and publishing uses the `social-publisher` skill if you have it.

## Install

**Easiest:** paste this into Claude Code:

> Install this: https://github.com/SheikhSakhi/reel-factory — clone it and run install.sh

**Manual:**

```bash
git clone https://github.com/SheikhSakhi/reel-factory.git
cd reel-factory && sh install.sh
```

Requirements: Node.js 18+, python3, git. The first render downloads Remotion's headless Chrome automatically. No API keys are needed.

Restart Claude Code after installing.

## Use

```
/reel-factory 3 habits that make you better at chess - 20s, CTA "follow for more"
```

You get `~/Projects/reel-studio/out/<slug>.mp4`. Run `npm run studio` inside `~/Projects/reel-studio` to tweak a reel by hand in the live editor.

Optional voice-over, free and with no key: `pip3 install edge-tts`, then ask for a voice-over in your request.

## What gets installed

- `~/.claude/skills/reel-factory/`: the orchestrator skill
- `~/.claude/agents/reel-*.md`: the 6 agents
- `~/Projects/reel-studio/`: the Remotion project (animation kit, demo reel, sound-effects generator, render and QA scripts). Set `REEL_STUDIO_DIR` to put it somewhere else.
